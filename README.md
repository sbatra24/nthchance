# nthchance

**Play the House.** A browser game where you run the casino instead of playing at one.

You set the odds, the promos and the jackpot, then watch what gamblers do with them. The end screen tells you whether a losing run was overspend or bad luck, and can fast-forward the house a year to show where it lands.

Live at [nthchance.com](https://nthchance.com).
